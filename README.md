# 오늘의 수산

프론트엔드 초안입니다. 가격 흐름과 관련 정보를 확인하는 화면 및 인터랙션을 구현했으며, 현재 표시되는 가격·기사·분석·채팅 내용은 모두 예시 데이터입니다.

## 주요 화면

- **홈:** 갈치, 고등어, 물오징어 가격 요약과 품목 검색
- **품목 상세:** 반월·월별 가격 차트, 기간별 Price Insight, 최근 이슈, 데이터 품질 정보
- **익명 채팅:** 서버 연결 없이 동작하는 로컬 시뮬레이션

화면 이동은 URL 해시를 사용합니다. 예: `#/products/hairtail`.

## 실행 방법

Node.js와 npm이 설치된 환경에서 다음 명령을 실행합니다.

```bash
npm install
npm run dev
```

개발 서버는 기본적으로 `http://localhost:5173`에서 실행됩니다.

## 빌드

```bash
npm run build
npm run preview
```

`npm run build`는 배포용 정적 파일을 `dist/`에 생성합니다. `npm run preview`는 해당 빌드 결과를 로컬에서 확인합니다.

## 기술 스택

- React 19
- TypeScript
- Vite
- Tailwind CSS 4

## 데이터 및 범위

현재 데이터는 `src/products.ts`에 정의된 프론트엔드 목업입니다. 실제 가격 API, 기사 제공처, 채팅 서버와 연결되어 있지 않습니다. 따라서 화면에 표시되는 가격이나 분석은 실제 정보로 사용하면 안 됩니다.

이 저장소는 서비스 구현 전 단계의 초안이며, 실제 데이터 연동과 운영 환경에 맞는 검토가 필요합니다.
